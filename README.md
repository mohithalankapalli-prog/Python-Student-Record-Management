Python Student Record Management System

Project Description

This is a Python-based Student Record Management System used to store and manage student records.

Technologies Used

- Python
- CSV
- JSON

Features

- Add Student Records
- View Student Records
- Search Student Records
- Update Student Details
- Delete Student Records
- Import CSV
- Export CSV
- Import JSON
- Export JSON

How to Run

Run the following command:

"python student_record_management.py"
